GHOST IMPORTS - SISTEMA COMPLETO CON SESIONES Y MYSQL WORKBENCH
=======================================================

1. CÓMO VER TU BASE DE DATOS EN MYSQL WORKBENCH:
-------------------------------------------------------
Tu base de datos "ghost_imports" ya está creada y conectada en tu MySQL local.
Para verla en MySQL Workbench:
1. Abre MySQL Workbench.
2. Haz clic en tu conexión "Local instance MySQL80".
3. En la barra izquierda (sección "SCHEMAS"), haz clic derecho y selecciona "Refresh All" (o pulsa el botón de actualizar 🔄).
4. Verás la base de datos "ghost_imports" con:
   - Tabla "usuarios": Contiene los clientes registrados y administradores.
   - Tabla "pedidos": Contiene la información de cada pedido y del cliente que compró.
   - Tabla "pedido_detalles": Prendas, tallas, cantidades y precios de cada pedido.
   - Vistas listas para consultar:
     * vista_usuarios_registrados (SELECT * FROM vista_usuarios_registrados;)
     * vista_pedidos_clientes (SELECT * FROM vista_pedidos_clientes;)
     * vista_pedidos_articulos (SELECT * FROM vista_pedidos_articulos;)
